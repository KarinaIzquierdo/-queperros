# Mas Que Perros

Sistema de gestión para guardería y entrenamiento canino.

## Características
- Gestión de usuarios y roles (Admin, Dueño, Entrenador).
- Reservas de servicios de entrenamiento y hotel canino.
- Seguimiento personalizado de mascotas.
- Plan Padrino para perros rescatados.
- Notificaciones dinámicas.
- Galería de fotos por mascota.

## Tecnologías
- PHP 8.3
- Laravel 12
- MySQL
- Blade Templates
- Tailwind CSS

## Instalación Local
1. Clonar el repositorio.
2. Ejecutar `composer install`.
3. Configurar el archivo `.env`.
4. Ejecutar `php artisan migrate`.
5. Ejecutar `php artisan serve`.
